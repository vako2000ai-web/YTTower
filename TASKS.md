# YTTower: список задач

## Этап 0. Подготовка репозитория

- [ ] Добавить `README.md` с описанием проекта, запуском и параметрами.
- [ ] Создать Vite + TypeScript проект.
- [ ] Подключить Three.js.
- [ ] Настроить `npm`-скрипты: `dev`, `build`, `preview`, `lint`.
- [ ] Добавить базовые конфиги: `tsconfig.json`, `vite.config.ts`, `.gitignore`.
- [ ] Зафиксировать структуру папок `src`.

## Этап 1. Базовая 3D-сцена

- [ ] Создать `GameApp` для инициализации приложения.
- [ ] Создать Three.js сцену, камеру, свет и WebGL renderer.
- [ ] Реализовать основной render loop.
- [ ] Добавить обработку resize окна.
- [ ] Настроить камеру так, чтобы башня была центральным объектом кадра.
- [ ] Добавить простой фон неба.

## Этап 2. Конфигурация и параметры запуска

- [ ] Создать модуль `Config`.
- [ ] Поддержать параметр `floors` / `N`.
- [ ] Сделать значение по умолчанию `100` этажей.
- [ ] Поддержать параметры скорости башни, частоты звезд, частоты облаков, гравитации и силы отскока.
- [ ] Добавить чтение параметров из URL.
- [ ] Добавить опциональный `seed` для воспроизводимой генерации.

## Этап 3. Башня и этажи

- [ ] Создать модули `Tower`, `Floor`, `Sector`.
- [ ] Генерировать башню из `N` этажей.
- [ ] Разделить каждый этаж на 4 сектора.
- [ ] Гарантировать один серый сектор на каждом этаже.
- [ ] Добавить 4 игровых цвета для цветных секторов.
- [ ] Реализовать вращение башни вокруг вертикальной оси.
- [ ] Реализовать определение сектора под попрыгунчиком.
- [ ] Реализовать визуальное разрушение пробитого этажа.
- [ ] Удалять или скрывать пробитые этажи без накопления лишних объектов.

## Этап 4. Попрыгунчик и персонажи

- [ ] Создать модуль `Jumper`.
- [ ] Реализовать вертикальное движение: прыжок, падение, отскок.
- [ ] Создать `CharacterFactory`.
- [ ] Добавить набор мультяшных персонажей-заготовок.
- [ ] Выбирать случайного персонажа на каждый забег.
- [ ] Добавить визуальные состояния персонажа: прыжок, падение, удар, бонус.
- [ ] Добавить индикатор активного цветового бонуса на персонаже.

## Этап 5. Аркадная физика и столкновения

- [ ] Создать `PhysicsSystem`.
- [ ] Создать `CollisionSystem`.
- [ ] Реализовать гравитацию.
- [ ] Реализовать силу отскока.
- [ ] Реализовать контакт с этажом.
- [ ] При контакте определять, можно ли пробить сектор.
- [ ] Пробивать серый сектор без бонуса.
- [ ] Отталкиваться от непробиваемого цветного сектора.
- [ ] Продолжать цепное пробитие при серии пробиваемых этажей.
- [ ] Сбрасывать эффект замедления при любом контакте с этажом.

## Этап 6. Звездочки

- [ ] Создать `StarManager`.
- [ ] Генерировать звездочки случайно.
- [ ] Реализовать движение звездочек по небу.
- [ ] Добавить 4 цветные звездочки по цветам секторов.
- [ ] Добавить золотистую звездочку.
- [ ] Реализовать столкновение попрыгунчика со звездочкой.
- [ ] Цветная звездочка должна давать одноразовый бонус на пробитие сектора такого же цвета.
- [ ] Золотистая звездочка должна давать одноразовый универсальный пробой.
- [ ] После использования бонус должен исчезать.
- [ ] Добавить визуальный эффект подбора звездочки.

## Этап 7. Облака

- [ ] Создать `CloudManager`.
- [ ] Генерировать облака случайно.
- [ ] Реализовать медленное движение облаков по небу.
- [ ] Реализовать столкновение попрыгунчика с облаком.
- [ ] При попадании в облако уменьшать скорость падения в 2 раза.
- [ ] Не складывать эффект от нескольких облаков.
- [ ] Сбрасывать замедление при следующем контакте с этажом.
- [ ] Добавить визуальный эффект замедления.

## Этап 8. Игровой забег

- [ ] Создать `GameState`.
- [ ] Создать `RunManager`.
- [ ] Реализовать состояния `BOOT`, `RUN_START`, `PLAYING`, `FINISHED`, `RESULT_SCREEN`, `RESTARTING`.
- [ ] Запускать таймер в начале забега.
- [ ] Завершать забег, когда пробиты все этажи.
- [ ] Останавливать таймер после последнего этажа.
- [ ] Автоматически запускать новый забег после табло.
- [ ] Увеличивать номер забега.
- [ ] Генерировать новую башню и нового персонажа для каждого забега.

## Этап 9. Счет и статистика

- [ ] Создать `ScoreSystem`.
- [ ] Считать пробитые этажи.
- [ ] Считать итоговое время.
- [ ] Считать очки.
- [ ] Считать пойманные звездочки.
- [ ] Считать пойманные золотые звездочки.
- [ ] Считать максимальное комбо.
- [ ] Считать пробития цветных секторов через бонус.
- [ ] Сохранять лучший результат текущей сессии.
- [ ] Опционально сохранять рекорд в `localStorage`.

## Этап 10. HUD и табло

- [ ] Создать `HUD`.
- [ ] Показывать таймер.
- [ ] Показывать счет.
- [ ] Показывать прогресс этажей: `разбито / всего`.
- [ ] Показывать активный бонус.
- [ ] Показывать комбо.
- [ ] Показывать номер забега.
- [ ] Создать `ResultBoard`.
- [ ] Показывать табло результатов после окончания забега.
- [ ] Держать табло на экране 5 секунд.
- [ ] После табло автоматически начинать новый забег.

## Этап 13. MVP-приемка

- [ ] Приложение запускается в браузере.
- [ ] Игра стартует автоматически.
- [ ] По умолчанию создается 100 этажей.
- [ ] Можно задать другое количество этажей.
- [ ] Башня вращается.
- [ ] Попрыгунчик прыгает и падает.
- [ ] Серые сектора пробиваются.
- [ ] Цветные сектора без бонуса вызывают отскок.
- [ ] Звездочки появляются и дают одноразовый бонус.
- [ ] Бонус позволяет пробить сектор соответствующего цвета.
- [ ] Золотая звездочка дает универсальный пробой.
- [ ] Облако замедляет падение в 2 раза до контакта с этажом.
- [ ] После пробития всех этажей показывается табло.
- [ ] Табло отображается около 5 секунд.
- [ ] После табло начинается новый забег.
